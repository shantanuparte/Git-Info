# Git-Info

## A tool to see Github user info

### Features
- Search by username
- Display's user infomation

### Installation

Binaries are avaliable in releases page

[Download for linux]()

[Download for Windows]()

Run by 
```
./gitinfo {username}
```

### Build for own

Just clone the repo

```
git clone https://github.com/shantanuparte/GeoShan.git
```

and run it

```
go run . {username}
```
