# Git-Info

## A tool to see Github user info

### Features
- Search by username
- Display's user infomation

### Installation

Binaries are avaliable in releases page

[Download for linux](https://github.com/shantanuparte/Git-Info/releases/download/v1.0/gitinfo)

[Download for Windows](https://github.com/shantanuparte/Git-Info/releases/download/v1.0/gitinfo.exe)

Run by 
```
./gitinfo {username}
```

### Build for own

Just clone the repo

```
git clone https://github.com/shantanuparte/GeoShan.git
```

and run it

```
go run . {username}
```
